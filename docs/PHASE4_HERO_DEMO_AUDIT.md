## 3. Bug Fixes & Code Hardening

During Phase 4 verification, an edge-case variable shadowing bug in `backend/app/routes/challenges.py` was identified and surgically corrected:
- **Issue:** The query parameter `q: str = ""` was shadowed by `q = s.query(Challenge)`, causing an `AttributeError: 'Query' object has no attribute 'strip'` when search queries were executed.
- **Fix:** Renamed the SQLAlchemy query variable to `stmt = s.query(Challenge)` to eliminate parameter collision.
